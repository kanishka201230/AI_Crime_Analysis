# 🛡️ AI-Driven Crime Analytics & Visualization Platform


Live server link-https://ai-crime.netlify.app/

An AI-powered web application that helps law enforcement agencies analyze crime data, predict crime hotspots, visualize incidents, and support proactive policing through intelligent analytics and interactive dashboards.

---

## 📌 Problem Statement

Traditional crime management systems primarily store historical records and generate basic reports. They lack AI-driven prediction, hotspot detection, and real-time visualization, making proactive crime prevention and efficient decision-making difficult for law enforcement agencies.

---

## 🎯 Solution Overview

The AI-Driven Crime Analytics & Visualization Platform leverages Artificial Intelligence, Machine Learning, Geographic Information Systems (GIS), and interactive dashboards to analyze crime data, identify patterns, predict future crime hotspots, and assist investigators with AI-powered insights.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### Navigate to Project

```bash
cd YOUR_REPOSITORY
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```
